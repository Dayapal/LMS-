Chapter 01

What Is a Function?

❖

1.1  Definition

A function is a reusable block of code designed to perform a particular task. You can call it whenever you need that task to be performed.

Consider a student management system that calculates total marks. If you need to calculate totals for 100 students, writing the same calculation 100 times would be inefficient.

Instead, write one function and reuse it.

The function contains the calculation once, but you can call it with different values.

1.2  Real-World Analogy: A Vending Machine

Imagine a vending machine.

  1. You provide input by selecting a product and paying.
  2. The machine processes your selection.
  3. It produces an output, such as the selected product.

A function works similarly:

  • Input: Arguments supplied to the function.
  • Processing: The instructions inside the function.
  • Output: A returned value, if the function returns one.
Analogy, Summarised

Input goes in. Work happens. A result comes out. If the result never comes out — the caller gets nothing.

Chapter 01 · What Is a Function?

1.3  Why Do We Need Functions?

Functions help you:

  • Reuse code.
  • Avoid unnecessary duplication.
  • Break large programs into smaller tasks.
  • Test individual pieces of logic.
  • Make code easier to maintain.
  • Separate responsibilities.
  • Create reusable components of application behavior.

For example, a full-stack application may contain functions for calculating fees, validating input, formatting dates, processing API responses and checking user permissions.

Return Values

❖

4.1  What Does return Do?

The return statement ends the current function execution and optionally provides a value to the caller.

The returned value can be:

  • Assigned to a variable,
  • Passed to another function, or
  • Used inside an expression.

4.2  console.log() versus return

This is one of the most important distinctions in JavaScript.

Example A: Displaying a value

The function displays 30, but it does not return that value. The function's result is therefore undefined.

Example B: Returning a value

The function returns 30, which is stored in result.

console.log()return
Displays information in the consoleSends a value back to the caller
Does not itself determine the function's return valueDetermines the function's returned value
Useful for debugging and inspectionUseful for calculations and reusable logic
Professional rule

Use return when another part of your program needs the result. Use console.log() when you want to inspect or display information.

Chapter 04 · Return Values

4.3  A Function Can Return Early

Once a return statement executes, the function exits immediately.

4.4  What Happens Without return?

If a function completes without an explicit return value, it returns undefined.

An explicit bare return; also returns undefined.

4.5  Returning Objects

A function can return objects, arrays and other values — not just numbers or strings.

This pattern is useful for building structured data in applications.

The Return Contract

A function's return value is its handshake with the rest of the program. Print a message if you want — but return the data.

Chapter 09

Function Scope and Nested Functions

❖

9.1  Function Scope

A variable declared inside a function is generally available only within that function, subject to the applicable declaration and scope rules.

The variable result is local to calculate().

9.2  Nested Functions

A nested function is a function defined inside another function.

The inner function can access variables from its surrounding lexical scope.

This is the foundation of closures.

9.3  Scope Chain

When JavaScript needs to resolve an identifier, it searches the relevant lexical environments according to the language's scope rules.

The inner function can access names from its own scope, its enclosing function and the outer scope.

But an outer function cannot directly access a variable declared only inside its inner function.

This direction of access is important for understanding closures and encapsulation.

Chapter 10

Higher-Order Functions

❖

A higher-order function is a function that takes another function as an argument, returns a function, or does both.

Functions are first-class values in JavaScript, which means they can be stored in variables, passed to other functions and returned from functions.

10.1  Passing a Function as an Argument

processUser receives the function greet and calls it later.

Notice the difference

processUser(greet) passes the function.
processUser(greet("Riya")) calls greet immediately and passes its return value instead.

10.2  Returning a Function
