Chapter 01

The DOM Tree — The Stage

❖

When a browser loads HTML, it parses the markup and builds a tree of objects called the DOM. Every element, attribute, and text snippet becomes a node in this tree.

Real-Life Analogy: A Family Tree

Think of a family tree. There is a root ancestor, then children, then grandchildren. The DOM works exactly like this — every element has parents, children, and siblings.

Node Relationships You Will Use

RelationshipMeaning
parentNodeThe direct parent
childrenAll element children
firstElementChild / lastElementChildFirst / last element child
nextElementSibling / previousElementSiblingAdjacent siblings
Why This Matters

Selection, modification, events and dynamic creation all make sense only if you can picture the tree. Draw it whenever you get stuck.

Real-life analogy: Every student has a unique roll number. To find student 105, you search by that identifier. An HTML id works the same way.

Watch out

If the ID doesn't exist, getElementById() returns null. Accessing .textContent afterward throws a TypeError. Always check first:
