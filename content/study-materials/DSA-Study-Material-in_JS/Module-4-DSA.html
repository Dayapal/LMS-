1. Strings in JS

1–2 days  •  Immutability · Char codes · Method costs · Unicode trap

Three facts drive almost every string bug in JS: strings are immutable, every "change" creates a new string (cost O(n)), and characters can be turned into numbers with charCodeAt. Learn these and the patterns become easy.

1.1 Immutability — the printed page analogy

Analogy  an array is a whiteboard — you can rub out one letter and write another. A string is a printed page — to fix one typo, you must reprint the whole page.

let s = "cat";
s[0] = "b";            // silently ignored (TypeError in strict mode)
console.log(s);        // "cat"

s = "b" + s.slice(1);  // reprint: builds a NEW string "bat" - O(n)

// To edit many characters, copy to a whiteboard (array), edit, then print once:
const arr = s.split("");   // ["b", "a", "t"]
arr[2] = "g";
s = arr.join("");          // "bag"
Rule: need many edits ⇒ split(""), edit the array, join("") once.

Analogy  joining beads one at a time and re-threading the whole necklace each time is slow. Collect beads in a bowl (an array), then thread them once with join.

const result = parts.join("");

function reverseStr(s) {
  const a = s.split("");
  let l = 0, r = a.length - 1;
  while (l < r) {
    [a[l], a[r]] = [a[r], a[l]];   // swap
    l++;
    r--;
  }
  return a.join("");
}

1.7 The Unicode trap

"😀".length is 2, not 1: JS counts UTF-16 code units, and emoji use two. s.split("") breaks them into broken halves; [...s] or Array.from(s) keeps them whole. Interview problems usually promise ASCII or lowercase letters — but ask, because asking is a senior habit.

1.8 Think first

Think first:
1. Why is for (i…) { if (s.includes(s[i] + "x")) … } slow?
2. You need to change every vowel in a 10⁵-character string to '*'. Strategy?
3. Is s1 === s2 O(1)?
Answers:
1) includes is O(n) inside an O(n) loop → O(n²).
2) split, edit the array, join once → O(n).
3) No — O(n) in the worst case, since characters are compared.

2. Pattern 1 — Frequency Counting

2–3 days  •  "The tally register"

Whenever a question cares about which characters appear and how often, but not their order, count them in one pass into an array of 26 or a Map. That turns O(n²) "search for each character" solutions into O(n).

Analogy — the tally register
A class teacher doesn't remember who came in which order; she keeps one register with a column per student and adds a tally mark. To compare two classes, she compares registers, not the order students walked in.

Trigger words: anagram, permutation, "same characters", "first unique / non-repeating", "most frequent", "can be formed from".

2.0 Two tools

// 1) Lowercase a–z only: fixed array (fastest)
const count = new Array(26).fill(0);
for (const ch of s) count[ch.charCodeAt(0) - 97]++;

// 2) Any characters: Map
const freq = new Map();
for (const ch of s) freq.set(ch, (freq.get(ch) || 0) + 1);

2.1 Valid Anagram (LC 242)

Return true if t is a rearrangement of s.

Input: s = "listen", t = "silent" → true
Think first:
• What's a quick check that rules out many cases instantly?
• Brute force idea: sort both. Cost?
• Can you use one register instead of two?

Solution idea: different lengths ⇒ false immediately. Otherwise add +1 for each letter of s and −1 for each letter of t. If they are anagrams, every tally returns to zero. (Sorting works too, at O(n log n).)

function isAnagram(s, t) {
  if (s.length !== t.length) return false;
  const count = new Array(26).fill(0);
  for (let i = 0; i < s.length; i++) {
    count[s.charCodeAt(i) - 97]++;
    count[t.charCodeAt(i) - 97]--;
  }
  return count.every(c => c === 0);
}

2.2 First Unique Character (LC 387)

Return the index of the first character that appears exactly once, or −1.

Input: "loveletecode" → 2 ('v')
Think first:
• Brute force: for each character, scan the whole string to count it. Cost?
• Can one pass both count and know the order? If not, what about two passes?

Solution idea: pass 1 fills the register. Pass 2 walks the string in original order and returns the first index whose tally is 1. Two passes of O(n) is still O(n).

function firstUniqChar(s) {
  const count = new Array(26).fill(0);
  for (const ch of s) count[ch.charCodeAt(0) - 97]++;
  for (let i = 0; i < s.length; i++) {
    if (count[s.charCodeAt(i) - 97] === 1) return i;
  }
  return -1;
}

2.3 Group Anagrams (LC 49)

Group words that are anagrams of each other.

Input: ["eat", "tea", "tan", "ate", "nat", "bat"] → [["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
Analogy — the post office
Every anagram family needs the same postal code. Give each word a code that's identical for all its anagrams, then sort letters into bins by code.
Think first:
• What "signature" is the same for "eat" and "tea" but different for "tan"?
• Option A: sorted letters. Option B: the 26-tally written as a string. Which is faster for long words? 
function groupAnagrams(words) {
  const bins = new Map();
  for (const w of words) {
    const key = w.split("").sort().join("");   // postal code
    if (!bins.has(key)) bins.set(key, []);
    bins.get(key).push(w);
  }
  return [...bins.values()];
}

Complexity: n words of length k → O(n · k log k). With the tally key (count.join("#")) it becomes O(n · k).

2.4 Teacher's notes — common mistakes

  • Forgetting the length check in anagram problems.
  • Using s.indexOf(ch) === s.lastIndexOf(ch) for uniqueness — correct, but O(n²).
  • Assuming lowercase when the problem allows uppercase or spaces — use a Map then.
Variation to try alone: Ransom Note (LC 383) — can ransom be built from the letters of magazine? (Same register: add magazine, subtract ransom, any negative ⇒ false.)

3. Pattern 2 — Two Pointers on Strings

2 days  •  "Two inspectors on a bridge"

When a question compares a string with its mirror (palindromes, reversing), put one pointer at each end and walk them toward each other. Each step settles one pair, so n/2 steps finish the job in O(n) with O(1) extra space.

Analogy — two inspectors on a bridge
A bridge is painted symmetrically. Two inspectors start at opposite ends and walk toward the middle, checking that the tiles under their feet match. They never need to walk the bridge twice, and they're done when they meet.

Trigger words: palindrome, reverse, "from both ends", "in place", "ignore non-alphanumeric".

3.0 Template

let l = 0, r = s.length - 1;
while (l < r) {
  // 1. skip characters that don't count (move l or r, then continue)
  // 2. compare or swap s[l] and s[r]
  l++; r--;
}

3.1 Valid Palindrome (LC 125)

After lowercasing and removing non-alphanumeric characters, does the string read the same both ways?

Input: "Taco cat!" → true
Think first:
• The easy way: clean the string into a new one, then compare it with its reverse. What does that cost in memory?
• Can the inspectors simply step over spaces and punctuation instead of removing them?

Solution idea: don't build a cleaned copy. If s[l] isn't a letter or digit, move l; same for r. Compare the rest case-insensitively.

function isPalindrome(s) {
  const ok = c => /[a-z0-9]/i.test(c);
  let l = 0, r = s.length - 1;
  while (l < r) {
    if (!ok(s[l])) { l++; continue; }
    if (!ok(s[r])) { r--; continue; }
    if (s[l].toLowerCase() !== s[r].toLowerCase()) return false;
    l++; r--;
  }
  return true;
}

Follow-up (LC 680, Valid Palindrome II): you may delete at most one character. At the first mismatch, try two options — skip s[l] or skip s[r] — and check whether the remaining range is a palindrome. Still O(n).

3.2 Reverse Words in a String (LC 151)

Reverse the order of words; remove extra spaces.

Input: "the sky is blue" → "blue is sky the"
Think first:
In JS this is one line: s.trim().split(/\s+/).reverse().join(" "). An interviewer then asks: "Now do it without split." How?
If you read the string from the right, in what order do you meet the words?

Solution idea: scan from the end. Skip spaces, mark where a word ends, walk left to its start, slice it out. Words come out already reversed.

function reverseWords(s) {
  const words = [];
  let i = s.length - 1;
  while (i >= 0) {
    while (i >= 0 && s[i] === " ") i--;          // skip spaces
    if (i < 0) break;
    const end = i;
    while (i >= 0 && s[i] !== " ") i--;           // walk to word start
    words.push(s.slice(i + 1, end + 1));
  }
  return words.join(" ");
}

3.3 Reverse Only Letters (LC 917)

Reverse the letters; keep every non-letter in its place.

Input: "Ab-cD" → "Dc-bA"
Think first: which inspector rule from 3.1 can you reuse? (Strings are immutable — what do you need first?) 
function reverseOnlyLetters(s) {
  const a = s.split("");
  const isLetter = c => /[a-z]/i.test(c);
  let l = 0, r = a.length - 1;
  while (l < r) {
    if (!isLetter(a[l])) l++;
    else if (!isLetter(a[r])) r--;
    else { [a[l], a[r]] = [a[r], a[l]]; l++; r--; }
  }
  return a.join("");
}

  • continue after moving a skip-pointer is essential — otherwise you compare a punctuation mark.

4. Pattern 3 — Sliding Window on Strings

3–4 days  •  "The caterpillar"

For questions about the best substring (contiguous) that satisfies a rule, keep a window [l..r]: grow it on the right, and shrink it from the left only when the rule breaks. Each character enters and leaves once, so O(n) replaces the O(n²) or O(n³) of trying every substring.

Analogy — the caterpillar
A caterpillar crawls along a leaf. Its head (r) always moves forward and eats the next letter. If it eats something that makes it sick (a repeat, too many of a letter), its tail (l) pulls forward until it feels fine again. The tail never moves backward. We record the caterpillar's longest healthy length.

Trigger words: substring, "longest / shortest", "contains all", "at most k distinct", "without repeating", "permutation of s1 inside s2".

4.0 Variable window template

let l = 0, best = 0;
for (let r = 0; r < s.length; r++) {
  // 1. head eats s[r]: add it to the window's state
  // 2. while window is invalid: remove s[l] from state, l++
  // 3. window [l..r] is valid: best = Math.max(best, r - l + 1)
}

4.1 Longest Substring Without Repeating Characters (LC 3)

Input: "abcabcbb" → 3 ("abc")
Think first:
• How many substrings does a string of length n have? What does checking each one cost?
• When the head meets a letter already in the window, where must the tail jump to?
• What do you need to remember to make that jump in O(1)?

Solution idea: store the last index where each character was seen. If s[r] was last seen at position ≥ l (inside the window), jump the tail to just after it.

function lengthOfLongestSubstring(s) {
  const last = new Map();     // char -> last index seen
  let l = 0, best = 0;
  for (let r = 0; r < s.length; r++) {
    const ch = s[r];
    if (last.has(ch) && last.get(ch) >= l) {
      l = last.get(ch) + 1;   // tail jumps past the old copy
    }
    last.set(ch, r);
    best = Math.max(best, r - l + 1);
  }
  return best;
}

4.2 Permutation in String (LC 567) — fixed window

Does s2 contain a permutation of s1?

Input: s1 = "ab", s2 = "eidbaooo" → true
Think first:
• The window size is fixed: what is it?
• What do you compare the window's tally to at each step?
• How many tallies change when the window slides by one?

Solution idea: build a fixed window of size s1.length and slide it one step at a time, updating the tally by +1 for the entering character and −1 for the leaving one. If the tally ever equals s1's tally, return true.

function checkInclusion(s1, s2) {
  if (s1.length > s2.length) return false;
  const need = new Array(26).fill(0);
  const win  = new Array(26).fill(0);
  for (const ch of s1) need[ch.charCodeAt(0) - 97]++;
  for (let r = 0; r < s2.length; r++) {
    win[s2.charCodeAt(r) - 97]++;
    if (r >= s1.length) win[s2.charCodeAt(r - s1.length) - 97]--;
    if (r >= s1.length - 1 && win.every((v, i) => v === need[i])) return true;
  }
  return false;
}

5. Pattern 4 — Expand Around Center

2 days  •  "Ripples in a pond"

Every palindrome is symmetric around a center, so instead of testing every substring (O(n³)), try every center and grow outward while both sides match. There are 2n − 1 centers and each expansion is at most O(n), giving O(n²) time and O(1) space.

Analogy — ripples in a pond
Drop a stone at one spot; ripples spread out equally left and right. Keep spreading while the letter on the left ripple equals the letter on the right ripple. The moment they differ, the ripple dies. Drop a stone on every letter and in every gap between two letters.
Why gaps too?
"aba" has its center on the letter 'b' (odd length).
"abba" has its center in the gap between the two b's (even length).
Forgetting gaps is the #1 bug in this pattern.
Centers for a string of length n
String length nLetter centersGap centersTotal
5 ("babad")549 = 2n − 1

5.0 The helper — one ripple

// Expand from (l, r) while it's a palindrome; return its bounds
function expand(s, l, r) {
  while (l >= 0 && r < s.length && s[l] === s[r]) {
    l--; r++;
  }
  return [l + 1, r - 1];   // step back to the last matching pair
}

5.1 Longest Palindrome Substring (LC 5)

Input: "babad" → "bab" ("aba" is also accepted)
Think first:
• Brute force: every substring (n²) × check palindrome (n). Total?
• If you know "aba" is a palindrome, what single check tells you whether "xabax" is one? 
function longestPalindrome(s) {
  let start = 0, end = 0;
  for (let i = 0; i < s.length; i++) {
    for (const [l, r] of [expand(s, i, i), expand(s, i, i + 1)]) {
      // letter, gap
      if (r - l > end - start) { start = l; end = r; }
    }
  }
  return s.slice(start, end + 1);
}

5.2 Palindromic Substrings — count them (LC 647)

Count all palindromic substrings (same text at different positions counts separately).

Input: "aaa" → 6
Think first: each successful ripple step is one palindrome. So instead of tracking the longest, what do you add up? 
function countSubstrings(s) {
  let count = 0;
  const ripple = (l, r) => {
    while (l >= 0 && r < s.length && s[l] === s[r]) {
      count++;
      l--; r++;
    }
  };
  for (let i = 0; i < s.length; i++) {
    ripple(i, i);       // letter center
    ripple(i, i + 1);   // gap center
  }
  return count;
}

5.3 Teacher's notes

  • return [l + 1, r - 1]: the loop exits one step past the palindrome, so step back. Draw it once on paper and it sticks.
  • O(n²) is the expected interview answer. Manacher's algorithm does it in O(n) — know the name; learning it is optional.
  • When a problem says subsequence (not substring), characters needn't be adjacent → this pattern doesn't apply; that's dynamic programming.
Ripple rule 🪷
2n − 1 centers — n letters + n − 1 gaps.
Expand while both sides match.
Step back one to get the palindrome's bounds.

6. Pattern 5 — Scanning and Parsing

2 days  •  Careful one-pass walks

Many "easy" string questions are really about walking the string carefully once and handling runs, columns, or neighbour rules without off-by-one errors. They look simple and are where most interview bugs happen.

6.1 Longest Common Prefix (LC 14)

Input: ["flower", "flow", "flight"] → "fl"
Analogy — the roll-call by columns
Line up the words one below another like rows in a register. Read column 0 down the page: all 'f'? Then column 1: all 'l'? The first column with a different letter — or a word that has run out — ends the prefix.
Think first:
• Which word limits how long the prefix can possibly be?
• What happens with an empty array, or a single word? 
function longestCommonPrefix(strs) {
  if (strs.length === 0) return "";
  const first = strs[0];
  for (let col = 0; col < first.length; col++) {
    const ch = first[col];
    for (let row = 1; row < strs.length; row++) {
      if (col >= strs[row].length || strs[row][col] !== ch) {
        return first.slice(0, col);   // column broke: prefix ends here
      }
    }
  }
  return first;                        // first word is itself the prefix
}

6.2 String Compression (run-length encoding)

Replace each run of a repeated character with the character and its count. Return the original if the result isn't shorter.

Input: "aabcccccaaa" → "a2b1c5a3"
Analogy — the shopping list
You don't write "apple, apple, apple"; you write "apple × 3". But for a single banana, "banana × 1" is longer than "banana" — which is why we keep the original if compression doesn't help.
Think first:
• How do you know a run has ended?
• Instead of comparing neighbours one by one, can a second pointer jump over the whole run? 
function compress(s) {
  const out = [];
  let i = 0;
  while (i < s.length) {
    let j = i;
    while (j < s.length && s[j] === s[i]) j++;   // j stops at first different char
    out.push(s[i], String(j - i));                // char + run length
    i = j;                                        // jump to the next run
  }
  const res = out.join("");
  return res.length < s.length ? res : s;
}

6.3 Roman to Integer (LC 13)

Input: "MCMXCIV" → 1994
Analogy — the discount tag
Normally coins add up left to right, biggest first. But when a smaller value sits just before a bigger one, it's a discount sticker: subtract it instead of adding (IV = 5 − 1, CM = 1000 − 100).
Think first: to decide whether to add or subtract a symbol, which one other symbol do you need to look at? 
function romanToInt(s) {
  const val = { I: 1, V: 5, X: 10, L: 50, C: 100, D: 500, M: 1000 };
  let total = 0;
  for (let i = 0; i < s.length; i++) {
    const cur = val[s[i]], next = val[s[i + 1]] || 0;   // past the end ⇒ 0
    total += cur < next ? -cur : cur;
  }
  return total;
}

6.4 Teacher's notes — the off-by-one checklist

  • Reading s[i + 1] at the last index gives undefined in JS (no crash) — handle it explicitly, as || 0 does above.
  • After an inner while that advances j, set i = j — not i++, or you'll re-count the run.
  • Test every scanner on: empty string, length 1, all same characters, and a run at the very end.
Scanner rule 🔍
One pass, one state.
Use a second pointer to jump over runs.
Handle s[i+1] at the end explicitly.

Quick Reference — One-Page Recap

A Strings in JS — three facts

  • Immutable — every "change" creates a new string, cost O(n).
  • charCodeAt — 'a' = 97, 'A' = 65, '0' = 48. Index = code − 97.
  • Many edits → split(""), edit the array, join("") once.

B The five patterns

  1. Frequency counting — "tally register" — one pass, O(n).
  2. Two pointers — "two inspectors on a bridge" — O(n), O(1) space.
  3. Sliding window (variable) — "caterpillar" — O(n).
  4. Sliding window (fixed) — "stencil" — O(n).
  5. Expand around center — "ripples in a pond" — O(n²).
  6. Careful scan — "roll-call / shopping list" — O(n).

C Common traps

  • includes / slice / toLowerCase inside a loop → O(n²).
  • s.split("") breaks emoji — use [...s].
  • Anagram: always check length first.
  • Sliding window: tail never moves backward.
  • Expand around center: don't forget the gap centers.
  • Scanner: after j stops, set i = j, not i++.
  • Reading s[i+1] at the end gives undefined — handle it explicitly.
Reminder: the dry-run table is not optional. If you can't trace the window on "abba" or the ripple on "cbbd" by hand, you don't yet understand the pattern.
