SECTION A

Quick Concepts & Output Prediction  •  A1 – A12

A1 String "25" versus number 25

The string "25" is text; the number 25 is numeric. With strings, + concatenates; with numbers, + performs arithmetic.

let textValue = "25";
let numberValue = 25;
console.log(typeof textValue);   // string
console.log(typeof numberValue); // number
console.log(textValue + 5);      // "255"
console.log(numberValue + 5);    // 30
Dry run: The string operation joins characters; the numeric operation adds values.

A2 Predict the output

String + string concatenates. Number() converts each string before numeric addition.

let a = "10";
let b = "20";
console.log(a + b);
console.log(Number(a) + Number(b));
Dry run: "1020" then 30.

A3 Four falsy values

Examples include false, 0, an empty string (""), null, undefined, and NaN. Any four are sufficient.

Dry run: For example: Boolean(0) is false and Boolean("") is false.

A4 Predict the output for an empty name

An empty string is falsy, so the else branch executes.

let name = "";
if (name) {
  console.log("Exists");
} else {
  console.log("Empty");
}
Dry run: The condition is false; output is Empty.

A5 Last character using str[str.length - 1]

It returns the final character of a non-empty string because string indexes begin at 0. For an empty string, it returns undefined.

let str = "Hello";
console.log(str[str.length - 1]); // o
Dry run: length is 5; index 5 − 1 = 4, and str[4] is "o".

A6 slice() versus splice()

let a = [10, 20, 30, 40];
console.log(a.slice(1, 3));   // [20, 30]
console.log(a);               // [10, 20, 30, 40]
let removed = a.splice(1, 2);
console.log(removed);         // [20, 30]
console.log(a);               // [10, 40]
Dry run: slice end index is exclusive; splice modifies a.

A7 Which method transforms every element into a new array?

map() applies a callback to each element and returns a new array of the same length.

const doubled = [1, 2, 3].map(n => n * 2);
console.log(doubled); // [2, 4, 6]
Dry run: Three input elements produce three mapped elements.

A8 First match: find() or filter()?

find() returns the first matching element (or undefined). filter() returns an array containing every matching element.

const values = [10, 30, 40];
console.log(values.find(n => n > 20));   // 30
console.log(values.filter(n => n > 20)); // [30, 40]
Dry run: find stops at the first match; filter collects all matches.

A9 for...of versus for...in

for...of iterates over values from an iterable such as an array or string. for...in iterates over enumerable property keys, commonly object keys.

const nums = [7, 8];
for (const value of nums) console.log(value); // 7, 8
for (const index in nums) console.log(index); // "0", "1"
Dry run: The first loop yields values; the second yields keys / index strings.

A10 Recursion base case

A base case is the condition that stops recursive calls. Without a reachable base case, calls can continue until the runtime throws a stack overflow error.

function countDown(n) {
  if (n <= 0) return;   // base case
  console.log(n);
  countDown(n - 1);
}
Dry run: countDown(3) prints 3, 2, 1, then stops at n = 0.

A11 indexOf returns an index or −1

console.log([4, 8, 12].indexOf(8)); // 1
console.log([4, 8, 12].indexOf(9)); // -1
Dry run: Searches must distinguish index 0 from −1.

A12 Time complexity versus space complexity

Time complexity describes how the amount of work grows with input size. Space complexity describes how memory usage grows. Auxiliary space usually means extra memory beyond the input.

function firstItem(arr) {
  return arr[0]; // constant work, no growing extra structure
}
Dry run: Direct indexing is O(1) time and O(1) auxiliary space.
Section A takeaway:
Type coercion, falsy values, slice vs splice, find vs filter, and base cases — these six ideas cover almost every output-prediction trap. 🎯

B5 Count vowels case-insensitively

Convert each character to lowercase, then count a / e / i / o / u. This solution uses a loop rather than a regular-expression shortcut.

function countVowels(str) {
  let count = 0;
  for (const ch of str.toLowerCase()) {
    if ("aeiou".includes(ch)) count++;
  }
  return count;
}
console.log(countVowels("JavaScript")); // 3
Dry run: JavaScript lowercases to javascript; a, a, and i are vowels.
Complexity: O(n) time; O(n) space for the lowercase copy (or O(1) extra if lowercasing each character).

B6 Print first, third, and last array elements

Array indexes are zero-based: first = index 0, third = index 2, last = index length - 1.

const nums = [10, 20, 30, 40];
console.log(nums[0]);
console.log(nums[2]);
console.log(nums[nums.length - 1]);
Dry run: Output: 10, 30, 40.
Complexity: O(1) time, O(1) auxiliary space.

const nums = [10, 20, 30];

B8 Sum an array using a loop

function sumArray(arr) {

B9 push() and pop()

const nums = [1, 2];
nums.push(3);
const removed = nums.pop();
console.log(removed); // 3

B10 Why default sort() surprises numeric sorting

Default sort compares string representations, so numeric values may be ordered lexicographically. Supply a numeric comparator for ascending numeric order.

const nums = [1, 30, 4, 21];
nums.sort();
console.log(nums); // string-like order
const ascending = [1, 30, 4, 21].sort((a, b) => a - b);
console.log(ascending); // [1, 4, 21, 30]
Dry run: Comparator a - b is negative when a should come before b.
Complexity: Sorting is typically O(n log n) average in modern engines; exact implementation details are engine-dependent.

B11 Count even values

An even integer has remainder 0 when divided by 2.

function countEven(arr) {
  let count = 0;
  for (const n of arr) {
    if (n % 2 === 0) count++;
  }
  return count;
}
console.log(countEven([2, 7, 8, 5, 10])); // 3
Dry run: 2, 8, and 10 increment the count.
Complexity: O(n) time, O(1) auxiliary space.

B12 Find the minimum value in an array

function findMin(arr) {
  let min = arr[0];
  for (let i = 1; i < arr.length; i++) {
    if (arr[i] < min) min = arr[i];
  }
  return min;
}
console.log(findMin([8, -2, 4, -5])); // -5
Dry run: min: 8 → −2 → −2 → −5.
Complexity: O(n) time, O(1) auxiliary space.
Note: Input must be non-empty; an empty array needs an explicitly chosen result or validation.

B13 Linear search returns index or −1

Compare each value with the target; return immediately when a match is found.

function linearSearch(arr, target) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === target) return i;
  }
  return -1;
}
console.log(linearSearch([5, 8, 1, 9, 4], 9)); // 3
Dry run: Check indexes 0, 1, 2, then 3; value 9 matches at index 3.
Complexity: Best O(1), worst O(n) time; O(1) auxiliary space.

B14 Reverse an array in place with two pointers

Swap the left and right elements, then move both pointers toward the center. No second array is created.

function reverseInPlace(arr) {
  let left = 0;
  let right = arr.length - 1;
  while (left < right) {
    [arr[left], arr[right]] = [arr[right], arr[left]];
    left++;
    right--;
  }
  return arr;
}
console.log(reverseInPlace([1, 2, 3, 4, 5]));
Dry run: Swap indexes 0 and 4 → [5,2,3,4,1]; swap 1 and 3 → [5,4,3,2,1]; stop when pointers meet.
Complexity: O(n) time, O(1) auxiliary space.

B15 Palindrome check with two pointers

function isPalindrome(word) {
  let left = 0;
  let right = word.length - 1;
  while (left < right) {
    if (word[left] !== word[right]) return false;
    left++;
    right--;
  }
  return true;
}
console.log(isPalindrome("level")); // true
console.log(isPalindrome("hello")); // false
Dry run: level: l = l, e = e, center reached → true. Empty and one-character strings also return true.
Complexity: O(n) time, O(1) auxiliary space.
Section B pattern box 🧠
• String indexing → O(1)
• One pass over a string/array → O(n)
• Two pointers from both ends → O(n) time, O(1) space
• Any method that builds a new array → O(n) extra space

Objects, Nested Data & Array Methods  •  C1 – C15

C1 Read object properties with dot and bracket notation

const student = { name: "Asha", age: 20, marks: 88 };
console.log(student.name);    // Asha
console.log(student["age"]);  // 20
console.log(student.marks);   // 88
Dry run: The object stores key–value pairs.

C2 Why student[key] works

If key contains the string "marks", student[key] evaluates the property whose name is held in that variable. student.key would look for a literal property named key.

const student = { name: "Asha", marks: 88 };
const key = "marks";
console.log(student[key]); // 88
console.log(student.key);  // undefined
Dry run: key → "marks" → student["marks"] → 88.

C3 Print each key and value with for...in

for...in gives enumerable property keys. Use student[key] to retrieve each value.

const student = { name: "Asha", age: 20, marks: 88 };
for (const key in student) {
  console.log(key, student[key]);
}
Dry run: Output includes name Asha, age 20, marks 88; key order follows JavaScript property-order rules.

C4 Second student name and topper

Use index 1 for the second student. Track the student with the highest marks during one traversal.

const students = [
  { name: "Asha", marks: 88 },
  { name: "Ravi", marks: 95 },
  { name: "Mina", marks: 91 }
];
console.log(students[1].name); // Ravi
let topper = students[0];
for (const student of students) {
  if (student.marks > topper.marks) topper = student;
}
console.log(topper.name); // Ravi
Dry run: Start topper = Asha(88); Ravi(95) replaces it; Mina(91) does not.
Complexity: O(n) time, O(1) auxiliary space after the input array.

C5 Access a value in a 2D array

const matrix = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]

console.log(matrix[1][2]); // 6
Dry run: matrix[1] is [4, 5, 6]; its index 2 value is 6.

C6 Sum a 2D array using nested loops

The outer loop visits each row; the inner loop visits each value in that row.

function sumMatrix(matrix) {
  let sum = 0;
  for (let r = 0; r < matrix.length; r++) {
    for (let c = 0; c < matrix[r].length; c++) {
      sum += matrix[r][c];
    }
  }
  return sum;
}
console.log(sumMatrix([[1, 2], [3, 4]])); // 10
Dry run: sum: 0 → 1 → 3 → 6 → 10.
Complexity: O(r × c) time, O(1) auxiliary space for r rows and c columns.

C7 Double each number with map()

map returns a new array containing each transformed value.

const doubled = [2, 4, 6, 8].map(n => n * 2);
console.log(doubled); // [4, 8, 12, 16]
Dry run: Each input value is multiplied by 2; the original array remains unchanged.

C8 Filter marks >= 40

filter keeps values for which the callback returns true.

const passing = [30, 70, 45, 20, 90].filter(mark => mark >= 40);
console.log(passing); // [70, 45, 90]
Dry run: 30 and 20 are rejected; 70, 45, and 90 are kept.
Complexity: O(n) time, up to O(n) output space.

C9 Sum with reduce()

const total = [5, 10, 15].reduce((sum, value) => sum + value, 0);
console.log(total); // 30

C10 Find first value greater than 25

find returns the first element satisfying the condition.

const result = [10, 20, 30, 40].find(n => n > 25);

C11 Example for some() true and every() false

some is true when at least one element passes; every is false as soon as one element fails.

const nums = [2, 5, 8];
console.log(nums.some(n => n % 2 === 0));  // true
console.log(nums.every(n => n % 2 === 0)); // false
Dry run: some sees 2 (even) and can return true; every fails when it sees 5.

C12 Copy and merge arrays with spread

Spread expands iterable elements into a new array. These are shallow copies.

const original = [1, 2];
const copy = [...original];
const merged = [...[1, 2], ...[3, 4]];
console.log(copy);   // [1, 2]
console.log(merged); // [1, 2, 3, 4]
Dry run: The arrays contain the same primitive values but are separate array objects.

C13 Rest-parameter sum function

The ...args parameter gathers any number of arguments into an array.

function sumAll(...args) {
  let sum = 0;
  for (const value of args) sum += value;
  return sum;
}
console.log(sumAll(2, 4, 6)); // 12
console.log(sumAll());        // 0
Dry run: args is [2, 4, 6] in the first call and [] in the second.
Complexity: O(k) time for k arguments, O(1) extra space beyond the rest array created by JavaScript.

C15 Default parameter greeting

The default value is used when the argument is omitted or undefined, not for every falsy value.

function greet(name = "Student") {

SECTION D

Recursion, Node.js Input & Problem Solving  •  D1 – D10

D1 Recursively print n down to 1

Print n, then call the function with n - 1. Stop when n is below 1.

function countDown(n) {
  if (n < 1) return;
  console.log(n);
  countDown(n - 1);
}
countDown(4);
Dry run: Calls: countDown(4) prints 4 → countDown(3) prints 3 → 2 → 1 → countDown(0) returns. Base case: n < 1.

D2 Recursive factorial

For n ≥ 1, n! = n × (n − 1)!. The base case is 0! = 1 (also 1! = 1).

function factorial(n) {
  if (n < 0 || !Number.isInteger(n)) {
    throw new Error("n must be a non-negative integer");
  }
  if (n <= 1) return 1;
  return n * factorial(n - 1);
}
console.log(factorial(4)); // 24
Dry run: factorial(4) = 4 × factorial(3) = 4 × 3 × 2 × 1 = 24.
Complexity: O(n) time and O(n) call-stack space.

D3 Recursive sum from 1 through n

Use sum(n) = n + sum(n − 1), with sum(0) = 0.

function sumToN(n) {
  if (n <= 0) return 0;
  return n + sumToN(n - 1);
}
console.log(sumToN(4)); // 10
Dry run: sumToN(4) = 4 + 3 + 2 + 1 + 0 = 10.
Complexity: O(n) time, O(n) call-stack space; assumes n is a non-negative integer.

D4 If recursion has no reachable base case

Recursive calls may continue until JavaScript exceeds the call stack and throws a RangeError. A base case that exists but can never be reached has the same problem.

Dry run: Trace whether each recursive call moves toward the base case.

D8 Plain-language algorithm for minimum

  1. Assume the first array element is the minimum.
  2. Visit each remaining element.
  3. If the current value is smaller, update the minimum.
  4. Return the minimum.
function findMin(arr) {
  if (arr.length === 0) throw new Error("Array must not be empty");
  let min = arr[0];
  for (let i = 1; i < arr.length; i++) {
    if (arr[i] < min) min = arr[i];
  }
  return min;
}
Dry run: For [7, 3, 5], min begins at 7, changes to 3, then remains 3.
Complexity: O(n) time, O(1) auxiliary space.

D10 Why max initialized to zero fails for all-negative arrays

If max starts at 0, no negative value is greater than 0, so the function incorrectly returns 0 even though 0 is not in the array. Initialize from arr[0] or use negative infinity after validating non-empty input.

Dry run: max: −8 → −4 → −4.

SECTION E

DSA Patterns & Complexity  •  E1 – E20

E1 Return both minimum and maximum

function minMax(arr) {
  if (arr.length === 0) throw new Error("Array must not be empty");
  let min = arr[0], max = arr[0];
  for (let i = 1; i < arr.length; i++) {
    if (arr[i] < min) min = arr[i];
    if (arr[i] > max) max = arr[i];
  }
  return { min, max };
}
console.log(minMax([7, 2, 9, -1, 5]));
Dry run: Start min = max = 7; 2 updates min; 9 updates max; −1 updates min; 5 changes neither. Result (min: −1, max: 9).
Complexity: O(n) time, O(1) auxiliary space.

E2 Count positive, negative, and zero values

Use three counters and return them as object properties.

function countSigns(arr) {
  const counts = { positive: 0, negative: 0, zero: 0 };
  for (const n of arr) {
    if (n > 0) counts.positive++;
    else if (n < 0) counts.negative++;
    else counts.zero++;
  }
  return counts;
}
console.log(countSigns([-2, 0, 4, 0, -1, 7]));
Dry run: The values yield (positive: 2, negative: 2, zero: 2).
Complexity: O(n) time, O(1) auxiliary space.

E3 Find second-largest distinct number

Track the largest and second-largest distinct values. Return null if fewer than two distinct values exist.

function secondLargest(arr) {
  let largest = -Infinity;
  let second = -Infinity;
  for (const n of arr) {
    if (n > largest) {
      second = largest;
      largest = n;
    } else if (n < largest && n > second) {
      second = n;
    }
  }
  return second === -Infinity ? null : second;
}
console.log(secondLargest([10, 5, 8, 10, 3])); // 8
console.log(secondLargest([4, 4]));            // null
Dry run: 10 sets largest; 5 sets second; 8 replaces second; repeated 10 is ignored because it is not distinct. Result 8.
Complexity: O(n) time, O(1) auxiliary space.
Note: This version assumes finite numeric values; if −Infinity can be valid input, use explicit found flags instead of −Infinity sentinels.

E4 Count target frequency without filter() or reduce()

Increment a counter for each strict equality match.

function frequency(arr, target) {
  let count = 0;
  for (const value of arr) {
    if (value === target) count++;
  }
  return count;
}
console.log(frequency([2, 3, 2, 5, 3, 3], 3)); // 3
Dry run: The target 3 appears at indexes 1, 4, and 5.
Complexity: O(n) time, O(1) auxiliary space.

E5 Return distinct duplicate values

Use one set to track seen values and another to store values that repeat. A duplicate is added only once.

function findDuplicates(arr) {
  const seen = new Set();
  const duplicates = new Set();
  for (const value of arr) {
    if (seen.has(value)) duplicates.add(value);
    else seen.add(value);
  }
  return [...duplicates];
}
console.log(findDuplicates([1, 2, 1, 3, 2, 2])); // [1, 2]
Dry run: 1 repeats → duplicates = {1}; 2 repeats → {1, 2}; later 2 repeats but Set prevents a second report.
Complexity: O(n) expected time, O(n) auxiliary space.

E6 Missing number

function missingNumber(arr) {
  const n = arr.length + 1;
  const expected = n * (n + 1) / 2;
  let actual = 0;
  for (const value of arr) actual += value;
  return expected - actual;
}
console.log(missingNumber([1, 2, 3, 5])); // 4
Dry run: n = 5; expected sum = 5 × 6 / 2 = 15; actual = 1 + 2 + 3 + 5 = 11; missing = 15 − 11 = 4.
Complexity: O(n) time, O(1) auxiliary space.
Note: Assumes no duplicates, values within 1..n, and exactly one missing value.

E7 Move zeroes to the end in place

Use a write pointer for the next non-zero slot. First copy non-zero values forward in their original order; then fill the remaining slots with zero.

function moveZeroes(arr) {
  let write = 0;
  for (let read = 0; read < arr.length; read++) {
    if (arr[read] !== 0) arr[write++] = arr[read];
  }
  while (write < arr.length) arr[write++] = 0;
  return arr;
}
console.log(moveZeroes([0, 1, 0, 3, 12]));
Dry run: Non-zero values compact to [1, 3, 12, _, _]; fill blanks with zeros → [1, 3, 12, 0, 0].
Complexity: O(n) time, O(1) auxiliary space; mutates input.

E8 Common distinct elements of two arrays

Build a set from the second array and collect matches from the first array into a result set to avoid duplicates.

function intersection(a, b) {
  const valuesB = new Set(b);
  const result = new Set();
  for (const value of a) {
    if (valuesB.has(value)) result.add(value);
  }
  return [...result];
}
console.log(intersection([1, 2, 2, 3, 4], [2, 2, 4, 6])); // [2, 4]
Dry run: 2 and 4 exist in both arrays; duplicate appearances are collapsed.
Complexity: O(n + m) expected time, O(m + k) auxiliary space, where k is result size.

E9 Rotate an array right by one position

function rotateRight(arr) {
  if (arr.length === 0) return arr;
  const last = arr[arr.length - 1];
  for (let i = arr.length - 1; i > 0; i--) {
    arr[i] = arr[i - 1];
  }

  return arr;
}

E10 Two Sum by checking every pair

Check all pairs i < j. Return their indexes when their values add to target; otherwise return null.

function twoSumBrute(arr, target) {
  for (let i = 0; i < arr.length; i++) {
    for (let j = i + 1; j < arr.length; j++) {
      if (arr[i] + arr[j] === target) return [i, j];
    }
  }
  return null;
}
console.log(twoSumBrute([2, 7, 11, 15], 9)); // [0, 1]

E11 Optimize Two Sum with a hash map

Store each previously seen number and its index. For current value x, look for target − x; this avoids checking every pair.

function twoSum(arr, target) {
  const indexByValue = new Map();
  for (let i = 0; i < arr.length; i++) {
    const needed = target - arr[i];
    if (indexByValue.has(needed)) {
      return [indexByValue.get(needed), i];
    }
    indexByValue.set(arr[i], i);
  }
  return null;
}
console.log(twoSum([2, 7, 11, 15], 9)); // [0, 1]
Dry run: i = 0: need 7, not seen; store 2 → 0. i = 1: need 2, found at index 0 → [0, 1].
Complexity: O(n) expected time, O(n) auxiliary space. Map operations are expected O(1).

E12 Maximum subarray sum (Kadane's algorithm)

function maxSubarraySum(arr) {
  if (arr.length === 0) return null;
  let current = arr[0];
  let best = arr[0];
  for (let i = 1; i < arr.length; i++) {
    current = Math.max(arr[i], current + arr[i]);
    best = Math.max(best, current);
  }
  return best;
}
console.log(maxSubarraySum([-2, 1, -3, 4, -1, 2, 1, -5, 4])); // 6
Dry run: Key states: at 4 current = 4; then −1 gives 3; +2 gives 5; +1 gives 6; −5 gives 1; +4 gives 5. Best remains 6 from [4, −1, 2, 1].
Complexity: O(n) time, O(1) auxiliary space.
Note: Initializing from arr[0] correctly handles all-negative arrays.

E13 Check whether two strings are anagrams

Normalize by lowercasing and removing whitespace, then compare character frequencies. This policy treats case and spaces as irrelevant.

function areAnagrams(a, b) {
  const normalize = s => s.toLowerCase().replace(/\s+/g, "");
  const x = normalize(a), y = normalize(b);
  if (x.length !== y.length) return false;
  const counts = new Map();
  for (const ch of x) counts.set(ch, (counts.get(ch) || 0) + 1);
  for (const ch of y) {
    if (!counts.has(ch)) return false;
    counts.set(ch, counts.get(ch) - 1);
    if (counts.get(ch) === 0) counts.delete(ch);
  }
  return counts.size === 0;
}
console.log(areAnagrams("Dormitory", "Dirty room")); // true
Dry run: Both normalize to dormitory / dirtyroom; character counts match exactly.
Complexity: O(n + m) expected time, O(k) space for distinct characters.

E17 Complexity of in-place two-pointer reversal

The pointers move inward and each pair is swapped once. The array is modified directly without creating a second array.

function reverseInPlace(arr) {
  let left = 0, right = arr.length - 1;
  while (left < right) {
    [arr[left], arr[right]] = [arr[right], arr[left]];
    left++;
    right--;
  }
  return arr;
}

E18 Palindrome edge cases: empty and one-character strings

function isPalindrome(str) {
  let left = 0, right = str.length - 1;
  while (left < right) {
    if (str[left] !== str[right]) return false;
    left++;
    right--;
  }
  return true;
}
